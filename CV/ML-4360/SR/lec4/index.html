    Stereo Reconstruction¶

    Overview

    This lecture covers stereo reconstruction fundamentals including epipolar geometry, image rectification, block matching, Siamese networks, and end-to-end learning approaches.

    Preliminaries¶

    Epipolar Geometry¶

    Key Insight

    A point \(\bar{x}\) in the left image must be located on the epipolar line \(\tilde{l}_2\) in the right image.

    This reduces correspondence search to a 1D problem!

    For VGA images: ~640 instead of ~300k hypotheses (factor 480 reduction)

    Image Rectification¶

    What if both cameras face exactly the same direction?

    Rectified Configuration

    • Image planes are co-planar ⇒ Epipoles at infinity, epipolar lines parallel
    • Correspondence search along horizontal scanlines (simplifies implementation)

    Let \(K_1 = K_2 = R = I\) and \(t = (t, 0, 0)^\top\):

    \[\bar{x}_2^T \tilde{E} \bar{x}_1 = \bar{x}_2^T \begin{bmatrix} 0 & 0 & 0 \\ 0 & 0 & -t \\ 0 & t & 0 \end{bmatrix} \bar{x}_1 = ty_1 - ty_2 = 0\]

    Thus \(y_1 = y_2\) (same row in both images)

    What if images are not in the required setup?

    Solution: Rectification

    We can rewarp images through rotation, mapping both image planes to a common plane parallel to the baseline.

    For this rotation around the camera center, the 3D structure need not be known.

    Step 2: Find \(R_{rect}\)¶

    Given baseline \(\vec{T} = (t_x, t_y, t_z)^T\):

    \[e_1 = \frac{T}{||T||}\]
    \[e_2 = \frac{1}{\sqrt{T_x^2 + T_y^2}}(-T_y, T_x, 0)^T = [(0, 0, 1)^\top]_\times r_1\]
    \[e_3 = e_2 \times e_1\]
    \[\Rightarrow R_{rect} = \begin{bmatrix} e_1^T \\ e_2^T \\ e_3^T \end{bmatrix}\]

    Step 3: Adjust \(\tilde{x}_i\)¶

    • Warp first image: \(\tilde{x}_1' = KR_{rect}K_1^{-1}\bar{x}_1\)
    • Warp second image: \(\tilde{x}_2' = KRR_{rect}K_2^{-1}\bar{x}_2\)

    Coordinate Systems

    Different coordinate systems result in different perception of \(R_{rect}\). Thus \(R_{rect}' = RR_{rect}\)

    \(K\) is a shared projection matrix that can be chosen arbitrarily (e.g., \(K = K_1\)).

    In practice, the inverse transformation is used for warping (query the source).

    Disparity to Depth¶

    Key Formula

    Given baseline \(b\) and focal length \(f\): \(\(\text{depth} = \frac{bf}{\text{disparity}}\)\)

    Block Matching¶

    Algorithm

    1. Choose disparity range \([0, D]\)
    2. For all pixels \(x = (x, y)\) compute the best disparity ⇒ winner-takes-all (WTA)
    3. Apply left-right consistency check to remove outliers

    Assumption Violations¶

    Fronto-Parallel Assumption

    Block matching assumes all pixels inside the window are displaced by \(d\).

    This fronto-parallel assumption is often invalid:

    • Slanted surfaces deform perspectively when viewpoint changes
    • Window size trade-off: Small windows → ambiguities and noise; Large windows → smoothing but border bleeding

    Siamese Networks¶

    Training¶

    Loss Function: Hinge Loss¶

    \[L = \max(0, m + s_- - s_+)\]

    Components

    • \(s_-\) / \(s_+\): network score for negative/positive example
    • \(m\): margin (typically 0.2)
    • Loss is zero when positive similarity exceeds negative by at least margin \(m\)

    Training Process

    The network is trained by minimizing hinge loss computed over pairs of examples centered around the same image position, where one belongs to positive and one to negative class.

    Spatial Regularization¶

    Add Pairwise Terms

    Smoothness between adjacent pixels in addition to matching costs.

    Regularizer Formula
    Potts \(\psi_{smooth}(d, d') = [d \neq d']\)
    Truncated \(\ell_1\) \(\psi_{smooth}(d, d') = \min(\|d - d'\|, \tau)\)

    Reference: Statistical and Computational Theory of Range Images

    End-to-End Learning¶

    Definition

    End-to-end learning is a technique where the model learns all steps between initial input and final output. All parts are trained simultaneously instead of sequentially.

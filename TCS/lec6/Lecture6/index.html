    Language Containment Properties¶

    Overview

    This lecture establishes the Chomsky Hierarchy of language classes and proves fundamental results about decidability using counting arguments and diagonalization.

    The Chomsky Hierarchy¶

    Language Containment

    \[\text{Regular} \subsetneq \text{Context-Free} \subsetneq \text{Recursive} \subsetneq \text{Recursively Enumerable}\]
    Separation Example Language
    Regular → CF \(\{a^n b^n \mid n \geq 0\}\)
    CF → Recursive \(\{a^n b^n c^n \mid n \geq 0\}\)
    Recursive → RE \(A_{TM}\) (halting problem)

    Countability Theory¶

    Definitions¶

    Countable Set

    A set \(A\) is countable if:

    • \(A\) is finite, OR
    • There exists a bijection \(f: A \to \mathbb{N}\)

    Key Lemmas¶

    Lemma 1: Injection Characterization

    \(A\) is countable \(\iff\) there exists an injection \(f: A \to \mathbb{N}\)

    Proof

    (\(\Rightarrow\)) Bijection implies injection (trivial).

    (\(\Leftarrow\)) Given injection \(f: A \to \mathbb{N}\):

    1. Sort elements of \(A\) by their \(f\)-values
    2. Define bijection \(g: A \to \mathbb{N}\) by position in sorted order

    Corollary 1

    Any subset of a countable set is countable.

    Countability Results¶

    Lemma 2: \(\Sigma^*\) is Countable

    For any finite alphabet \(\Sigma\), the set of all strings \(\Sigma^*\) is countable.

    Proof Sketch

    Enumerate strings by: 1. First by length 2. Then lexicographically within each length

    See Waterloo Notes, Proposition 2.1

    Corollary 2

    The set of all Turing Machines is countable.

    Proof: Each TM has a finite description, encodable as a string.

    Uncountability¶

    Lemma 3: Languages are Uncountable

    The set of all languages over alphabet \(\Sigma\) is uncountable.

    Proof (Cantor's Diagonal Argument)

    Assume languages are countable: \(L_1, L_2, L_3, \ldots\)

    Construct \(L^* = \{w_i \mid w_i \notin L_i\}\)

    Then \(L^* \neq L_i\) for all \(i\) — contradiction!

    Fundamental Theorem

    Since:

    • Turing Machines are countable
    • Languages are uncountable

    There exist languages that are NOT recursively enumerable!

    The Halting Problem¶

    \(A_{TM}\): The Acceptance Problem¶

    Definition

    \[A_{TM} = \{\langle M, w \rangle \mid M \text{ is a TM and } M \text{ accepts } w\}\]

    Theorem 1: \(A_{TM}\) is RE¶

    Theorem

    \(A_{TM}\) is recursively enumerable (semi-decidable).

    Proof

    Construct TM \(E\) that semi-decides \(A_{TM}\):

    E = On input ⟨M, w⟩:
  1. Simulate M on w
  2. If M accepts → ACCEPT
  3. If M rejects → REJECT
  4. If M loops → LOOP (never halt)

    Theorem 2: \(A_{TM}\) is NOT Recursive¶

    Theorem

    \(A_{TM}\) is not recursive (undecidable).

    Proof (Diagonalization)

    Assume \(A_{TM}\) is recursive. Then some TM \(H\) decides it.

    Construct TM \(D\): 

    D = On input ⟨M⟩:
  1. Run H on ⟨M, ⟨M⟩⟩
  2. If H accepts → REJECT
  3. If H rejects → ACCEPT

    Paradox: What happens when \(D\) runs on \(\langle D \rangle\)?

    If \(D\) on \(\langle D \rangle\)... Then \(H\) on \(\langle D, \langle D \rangle \rangle\)... Contradiction!
    accepts accepts (so \(D\) rejects) ❌
    rejects rejects (so \(D\) accepts) ❌

    Therefore, \(H\) cannot exist, and \(A_{TM}\) is undecidable. ∎

    The Diagonal Language¶

    \(A_d\): Diagonal Non-Acceptance¶

    Definition

    \[A_d = \{\langle M \rangle \mid M \text{ is a TM that does NOT accept } \langle M \rangle\}\]

    Theorem 3: \(A_d\) is NOT RE¶

    Theorem

    \(A_d\) is not recursively enumerable.

    Proof

    Assume TM \(D\) semi-decides \(A_d\): 

    D = On input ⟨M⟩:
  1. If M ∈ A_d (M rejects ⟨M⟩) → ACCEPT
  2. If M ∉ A_d (M accepts ⟨M⟩) → REJECT or LOOP

    Paradox: Run \(D\) on \(\langle D \rangle\):

    If \(D\) on \(\langle D \rangle\)... Then... Contradiction!
    accepts \(D \in A_d\) means \(D\) rejects \(\langle D \rangle\) ❌
    rejects/loops \(D \notin A_d\) means \(D\) accepts \(\langle D \rangle\) ❌

    Complement Closure¶

    Theorem 4: RE + co-RE = Recursive¶

    Theorem

    If both \(L\) and \(\overline{L}\) are RE, then \(L\) is recursive.

    Proof

    Let \(M_1\) semi-decide \(L\) and \(M_2\) semi-decide \(\overline{L}\).

    Construct decider \(D\): 

    D = On input w:
  1. Run M₁ and M₂ in parallel on w
  2. If M₁ accepts → ACCEPT
  3. If M₂ accepts → REJECT

    One of them must accept (since \(w \in L\) or \(w \in \overline{L}\)).

    Theorem 5: \(\overline{A_{TM}}\) is NOT RE¶

    Theorem

    \(\overline{A_{TM}}\) is not recursively enumerable.

    Proof
    • We know \(A_{TM}\) is RE
    • We know \(A_{TM}\) is NOT recursive
    • By Theorem 4: If \(\overline{A_{TM}}\) were RE, then \(A_{TM}\) would be recursive
    • Contradiction! ∎

    Summary Table¶

    Classification of Key Languages

    Language Recursive? RE? co-RE?
    Regular languages ✓ ✓ ✓
    CFLs ✓ ✓ ✓
    \(A_{TM}\) ❌ ✓ ❌
    \(\overline{A_{TM}}\) ❌ ❌ ✓
    \(A_d\) ❌ ❌ ?

    Key Insight

    The diagonal argument is the fundamental technique for proving undecidability. It creates a paradox by self-reference.

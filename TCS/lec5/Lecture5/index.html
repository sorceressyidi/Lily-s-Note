    Turing Machine¶

    Overview

    The Turing Machine, invented by Alan Turing in 1936, is the most powerful model of computation. It can simulate any computer algorithm and forms the theoretical foundation of modern computing.

    Definition¶

    Turing Machine

    A Turing Machine is a 5-tuple \((K, \Sigma, \delta, s, H)\):

    Component Description
    \(K\) Finite set of states
    \(\Sigma\) Finite set of tape symbols (includes \(\triangleright\) and \(\sqcup\))
    \(s \in K\) Start state
    \(H \subseteq K\) Halt states (typically \(\{yes, no\}\))
    \(\delta\) Transition function

    Transition Function¶

    \[\delta: (K - H) \times \Sigma \rightarrow K \times (\Sigma \cup \{L, R\})\]

    Special Symbols

    • \(\triangleright\) — Left endmarker (cannot be overwritten)
    • \(\sqcup\) — Blank symbol (infinite supply on tape)

    Constraints:

    • \(\forall q \in K - H\): \(\delta(q, \triangleright) = (p, R)\) for some \(p\) (must move right from endmarker)
    • Actions: write a symbol OR move (\(L\)/\(R\))

    Configuration and Computation¶

    Configuration¶

    Definition

    A configuration is a snapshot of the TM's state: \(\((q, \triangleright w \underline{a} u) \in K \times \triangleright \Sigma^*\)\)

    • \(q\) — current state
    • \(w\) — tape contents to the left of head
    • \(a\) — symbol under head (underlined)
    • \(u\) — tape contents to the right

    Yield Relations¶

    Notation Meaning
    \((q_1, \triangleright w_1 a_1 u_1) \vdash_M (q_2, \triangleright w_2 a_2 u_2)\) One-step transition
    \(\vdash_M^*\) Zero or more steps

    Transition types:

    • Write: \(\delta(q_1, a_1) = (q_2, a_2)\) where \(a_2 \in \Sigma\)
    • Move Left: \(\delta(q_1, a_1) = (q_2, L)\)
    • Move Right: \(\delta(q_1, a_1) = (q_2, R)\)

    Acceptance and Decidability¶

    Acceptance¶

    Definitions

    Term Meaning
    \(M\) accepts \(w\) \((s, \triangleright \sqcup w) \vdash^* (yes, \ldots)\)
    \(M\) rejects \(w\) \((s, \triangleright \sqcup w) \vdash^* (no, \ldots)\)
    \(L(M)\) \(\{w \in \Sigma^* \mid M \text{ accepts } w\}\)

    Decidability¶

    Key Definitions

    Term Definition
    \(M\) decides \(L\) \(M\) accepts all \(w \in L\) AND rejects all \(w \notin L\)
    \(M\) semi-decides \(L\) \(M\) accepts all \(w \in L\) (may loop on \(w \notin L\))
    Recursive language Decided by some TM
    Recursively Enumerable Semi-decided by some TM

    Important

    Every recursive language is recursively enumerable, but not vice versa!

    Variants of Turing Machines¶

    Multi-tape TM¶

    \[\delta: (K - H) \times \Sigma^k \rightarrow K \times ((\Sigma - \{\triangleright\}) \cup \{L, R\})^k\]

    Other Variants¶

    Variant Description
    Two-way infinite tape No left endmarker
    Multi-head TM Multiple heads on one tape
    2D-tape TM Two-dimensional tape
    Random Access TM Can jump to any position

    Equivalence Theorem

    All variants are equivalent in computational power to the standard TM!

    Example: \(\{a^n b^n c^n\}\)¶

    TM for \(L = \{a^n b^n c^n \mid n \geq 0\}\)

    High-level algorithm:

    1. Check format: only \(a\)'s, then \(b\)'s, then \(c\)'s
    2. Mark leftmost \(a\) with \(X\)
    3. Scan right, mark leftmost \(b\) with \(Y\)
    4. Scan right, mark leftmost \(c\) with \(Z\)
    5. Return to leftmost unmarked \(a\), repeat
    6. Accept if all symbols are marked

    Non-deterministic TM¶

    Definition

    NTM uses a transition relation instead of function: \(\(\Delta \subseteq (K - H) \times \Sigma \times K \times (\Sigma \cup \{L, R\})\)\)

    Acceptance (NTM)¶

    NTM Semantics

    • Accepts \(w\): Some computation path reaches \(yes\)
    • Rejects \(w\): All computation paths reach \(no\)
    • Decides \(L\): All branches halt; accepts iff \(w \in L\)
    • Semi-decides \(L\): Accepts iff \(w \in L\); may not halt

    Example: Composite Numbers¶

    NTM for \(C = \{n \in \mathbb{N} \mid n \text{ is composite}\}\)

    NTM = On input n:
  1. Non-deterministically guess factors a, b > 1
  2. Verify a × b = n
  3. If yes, ACCEPT

    NTM = DTM Theorem¶

    Theorem

    Every NTM can be simulated by a DTM.

    Proof: BFS Simulation

    Use a 3-tape DTM:

    1. Tape 1: Input
    2. Tape 2: Working tape for simulation
    3. Tape 3: BFS queue of configurations

    Church-Turing Thesis¶

    Church-Turing Thesis

    Every algorithm can be simulated by a Turing Machine.

    Intuitive notion of "computability" = Turing computability

    Encoding Facts¶

    What Can Be Encoded

    • Any finite set can be encoded as a string
    • Any finite tuple of finite sets can be encoded
    • Graphs \(G = (V, E)\) can be encoded

    Standard Decision Problems¶

    \(A_{DFA}\): DFA Acceptance¶

    \(A_{DFA} = \{\langle D, w \rangle \mid D \text{ accepts } w\}\)

    M = On input ⟨D, w⟩:
  1. Simulate D on w
  2. Accept if D accepts; Reject otherwise

    ✓ Decidable

    \(A_{NFA}\): NFA Acceptance¶

    \(A_{NFA} = \{\langle B, w \rangle \mid B \text{ accepts } w\}\)

    Reduction: NFA → DFA → solve \(A_{DFA}\)

    ✓ Decidable

    \(E_{DFA}\): DFA Emptiness¶

    \(E_{DFA} = \{\langle D \rangle \mid L(D) = \emptyset\}\)

    M = On input ⟨D⟩:
  1. DFS from start state
  2. ACCEPT if no accepting state reachable
  3. REJECT otherwise

    ✓ Decidable

    \(EQ_{DFA}\): DFA Equivalence¶

    \(EQ_{DFA} = \{\langle D_1, D_2 \rangle \mid L(D_1) = L(D_2)\}\)

    Idea: Check if symmetric difference is empty \(\(L(D_1) \triangle L(D_2) = (L(D_1) \cup L(D_2)) - (L(D_1) \cap L(D_2))\)\)

    ✓ Decidable

    \(A_{CFG}\): CFG Membership¶

    \(A_{CFG} = \{\langle G, w \rangle \mid G \text{ generates } w\}\)

    Using Chomsky Normal Form:

    • Convert \(G\) to CNF
    • Enumerate all derivations of length \(\leq 2|w| - 1\)

    ✓ Decidable (CYK algorithm: \(O(n^3)\))

    Problem Input Decidable?

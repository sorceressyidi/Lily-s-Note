    堆栈¶

    堆栈是函数调用和局部变量的基础

    理解堆栈的工作原理对于调试和逆向工程至关重要。

    📌 堆栈段定义¶

    stk segment stack       ; 堆栈只能定义一个
    db 200h dup('S')    ; 512 字节堆栈空间
stk ends

; 在代码段中声明
assume cs:code, ds:data, ss:stk

    程序加载后的初始化

    操作系统 (DOS) 会自动设置：

    寄存器 值
    CS code 段地址
    IP offset main
    SS stk 段地址
    SP 堆栈大小 (如 200h)
    DS, ES PSP 段地址

    ⚠️ 未定义堆栈时¶

    默认行为

    如果源程序中没有定义堆栈段：

    SS = 首段的段地址 (如 1000h)
SP = 0

    初始状态:
┌─────────────┐
│   code      │ 1000:0000
├─────────────┤
│   ...       │
├─────────────┤
│             │ 1000:FFFE ← SP-2 (第一次 push)
├─────────────┤
│   ??        │ 1000:FFFF
└─────────────┘

    堆栈溢出风险

    • 用户可用内存到 9000:FFFF
    • 如果 push 太多，SP 会向低地址增长
    • 可能覆盖 code 段数据，导致程序崩溃

    📦 堆栈操作¶

    PUSH 操作¶

    push ax
; 等价于:
; SP = SP - 2
; SS:[SP] = AX

    POP 操作¶

    pop ax
; 等价于:
; AX = SS:[SP]
; SP = SP + 2

    🔢 小端存储¶

    x86 使用小端字节序

    低字节存放在低地址

    push 1234h 后的堆栈:
┌─────────┐
│   34    │ SS:SP   (低字节)
├─────────┤
│   12    │ SS:SP+1 (高字节)
└─────────┘

    📐 堆栈帧 (Stack Frame)¶

    函数调用时的堆栈结构

    ; 调用 f(10, 20)
push 20         ; 参数 2
push 10         ; 参数 1
call f          ; 压入返回地址

    函数内部：

    f:
    push bp         ; 保存旧 BP
    mov bp, sp      ; 建立栈帧
    sub sp, 4       ; 为局部变量分配空间

    ; [bp+4] = 返回地址
    ; [bp+6] = 参数 1 (10)
    ; [bp+8] = 参数 2 (20)
    ; [bp-2] = 局部变量 1
    ; [bp-4] = 局部变量 2

    mov sp, bp      ; 释放局部变量
    pop bp          ; 恢复旧 BP
    ret

    堆栈布局：

    高地址
┌─────────────┐
│ 参数 2 (20) │ [bp+8]
├─────────────┤
│ 参数 1 (10) │ [bp+6]
├─────────────┤
│ 返回地址    │ [bp+4]
├─────────────┤
│ 旧 BP       │ [bp] ← BP 指向这里
├─────────────┤
│ 局部变量 1  │ [bp-2]
├─────────────┤
│ 局部变量 2  │ [bp-4] ← SP 指向这里
└─────────────┘
低地址

    💡 PSP (程序段前缀)¶

    PSP 信息

    • PSP 是一个 100h (256) 字节的内存块
    • 位于当前程序首段的前面
    • 由操作系统分配
    • 包含命令行参数等信息
    // 对应 C 语言的 main 参数
int main(int argc, char *argv[]) { }
// 命令行: main.exe 123 xyz
// argv[0] = "main.exe"
// argv[1] = "123"
// argv[2] = "xyz"

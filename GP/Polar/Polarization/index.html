    偏振（Polarization）¶

    Overview

    本讲涵盖线偏振、圆偏振、Jones 矢量、自然光、偏振片以及布儒斯特角。

    预备知识¶

    波的传播方向

    考虑 \(\cos(kx + \omega t)\) 和 \(\cos(kx - \omega t)\)：

    形式 传播方向
    \(\cos(kx + \omega t)\) 沿 \(-x\) 轴传播
    \(\cos(kx - \omega t)\) 沿 \(+x\) 轴传播

    偏振¶

    干涉的条件

    观察两波干涉需要：

    • 两束波频率 \(\omega\) 几乎相同
    • 干涉波振幅相近
    • 两源之间相位差保持恒定

    本讲我们考虑 \(\vec{E}\) 的方向。

    光是横向电磁波。到目前为止，我们只考虑了电场方向恒定（虽然大小和符号随时间变化）的光。

    一般地，我们可以考虑两束同频率、沿同一方向 \(\hat{z}\) 在同一区域传播的简谐光波：

    \[\vec{E}_x(z,t) = \hat{i}E_{0x}\cos(kz - \omega t)\]
    \[\vec{E}_y(z,t) = \hat{j}E_{0y}\cos(kz - \omega t + \varepsilon)\]

    偏振及其数学描述¶

    线偏振¶

    线偏振条件

    如果 \(\varepsilon\) 为零或 \(\pm 2\pi\) 的整数倍，合成波为： \(\(\vec{E} = (\hat{i}E_{0x} + \hat{j}E_{0y})\cos(kz - \omega t)\)\)

    圆偏振¶

    右旋圆偏振

    当两分量波振幅相等且 \(\varepsilon = -\pi/2 + 2m\pi\)（\(m\) 为整数）时： \(\(\vec{E} = E_0(\hat{i}\cos(kz - \omega t) + \hat{j}\sin(kz - \omega t))\)\)

    左旋圆偏振

    当两分量波振幅相等且 \(\varepsilon = \pi/2 + 2m\pi\)（\(m\) 为整数）时： \(\(\vec{E} = E_0(\hat{i}\cos(kz - \omega t) - \hat{j}\sin(kz - \omega t))\)\)

    振幅不变，但 \(\vec{E}\) 在固定 \(z\) 处逆时针旋转，即左旋圆偏振。

    重要关系

    线偏振波可以由两束振幅相等、旋转方向相反的圆偏振波合成。

    Jones 矢量¶

    常见偏振态的 Jones 矢量

    水平和垂直线偏振： \(\(|H\rangle = \begin{pmatrix}1\\0\end{pmatrix}, \quad |V\rangle = \begin{pmatrix}0\\1\end{pmatrix}\)\)

    对角线偏振（+45° 和 -45°）： \(\(|D\rangle = \frac{1}{\sqrt{2}}(|H\rangle + |V\rangle) = \frac{1}{\sqrt{2}}\begin{pmatrix}1\\1\end{pmatrix}\)\)

    \[|A\rangle = \frac{1}{\sqrt{2}}(|H\rangle - |V\rangle) = \frac{1}{\sqrt{2}}\begin{pmatrix}1\\-1\end{pmatrix}\]

    注意

    我们只关心偏振，所以矢量是归一化的（单位长度）。

    圆偏振的 Jones 矢量

    右旋圆偏振： \(\(|R\rangle = \frac{1}{\sqrt{2}}(|H\rangle - i|V\rangle) = \frac{1}{\sqrt{2}}\begin{pmatrix}1\\-i\end{pmatrix}\)\)

    左旋圆偏振： \(\(|L\rangle = \frac{1}{\sqrt{2}}(|H\rangle + i|V\rangle) = \frac{1}{\sqrt{2}}\begin{pmatrix}1\\i\end{pmatrix}\)\)

    正交性¶

    数学空间

    在干涉讲座中，我们讨论的是二维实空间 \(\mathbb{R}^2\) 中的叠加。

    该空间也等价于一维复空间 \(\mathbb{C}^1\)，或二分量实向量空间。

    现在，有了偏振，我们将一维复空间 \(\mathbb{C}^1\) 推广到二维复空间 \(\mathbb{C}^2 = \mathbb{C}^1 \otimes \mathbb{C}^1\)，即二分量复向量空间（Jones 矢量表示）。

    额外的 \(\mathbb{C}^1\) 空间由两个正交的线偏振态 \(|H\rangle\) 和 \(|V\rangle\) 张成。

    正交的定义

    两个复向量 \(\vec{A}\) 和 \(\vec{B}\) 正交当且仅当： \(\(\langle A|B\rangle \equiv \vec{A}^* \cdot \vec{B} = 0\)\)

    正交对

    任何偏振态都有相应的正交态： \(\(\langle H|V\rangle = \langle D|A\rangle = \langle L|R\rangle = 0\)\)

    任何偏振态都可以用这些正交集中任一对的线性组合来描述。

    量子力学联系

    这些概念在量子力学中非常重要，涉及正交归一化波函数。

    单色光与自然光¶

    光波列与单色光¶

    准单色光

    实际上，非激光光源最好也只能发出准单色光波列，其频率可以用钟形高斯函数表示。

    即：辐照度（因此振幅的平方根）对频率的分布是高斯型的，宽度为 \(\Delta\omega = 2\pi\Delta\nu\)。

    光波列特性

    准单色光类似于一系列随机相位的有限波列。

    这种扰动近似正弦，虽然频率围绕某个平均值缓慢变化。

    此外，振幅也会波动，但这也是相对缓慢的变化。

    相干时间

    平均组成波列存在的时间大约为相干时间： \(\(\Delta t_c = \frac{1}{\Delta\nu}\)\)

    相干长度与相干时间

    • 相干长度：两列波能发生干涉的最大光程差 \(\(\delta_M = \frac{\lambda^2}{\Delta\lambda}\)\) 其中 \(\lambda\) 为中心波长

    • 相干时间：光通过相干长度所需时间 \(\(T_c = 1/\Delta\nu\)\)

    • 光的单色性越好，相干长度和相干时间越长，时间相干性也越好

    理想单色平面波

    理想化的单色平面波必须描绘成无限波列。

    如果这种扰动分解成两个垂直于传播方向的正交分量，它们必须有相同的频率、无限延伸，因此相互相干（即 \(\varepsilon = \text{常数}\)）。

    重要结论

    完美的单色平面波总是偏振的。

    激光的优势

    当今最出色的光源是激光。

    在温度变化和振动被精心抑制的最佳条件下，激光可以非常接近其频率稳定性的理论极限运行。

    例如，He-Ne 连续气体激光器在 \(\lambda_0 = 1153\) nm 处达到了约 \(8 \times 10^{-14}\) 的短期频率稳定性，对应约 \(\Delta\nu = 20\) Hz 的极窄带宽。

    自然光¶

    自然光定义

    自然光由快速变化（约 \(10^{-8}\) s）的不同偏振态序列组成。

    也称为非偏振光或随机偏振光。

    数学表示

    我们可以用两个任意的、不相干的、正交的、等振幅线偏振波来数学表示自然光（即相对相位差快速随机变化的波）。

    相干性¶

    相干性定义

    相干性是波在不同（时间和空间）点测量的相位之间相关性的度量。

    类型 描述 物理意义
    时间相干性 沿传播方向不同点相位的相关性 光源的单色性
    空间相干性 垂直于传播方向不同点相位的相关性 波前相位的均匀性

    部分偏振光

    实际上，光通常既不是完全偏振的，也不是完全非偏振的。

    更常见的是，电场矢量以既不完全规则也不完全不规则的方式变化，这种光学扰动是部分偏振的。

    一种有用的描述方式是将其看作特定量的自然光和偏振光的叠加。

    偏振片¶

    偏振片原理

    非偏振的可见光可以通过偏振片（Polaroid 片）转换为偏振光。

    结构

    偏振片由嵌入塑料中的某些长分子组成。

    当光通过偏振片时，平行于偏振方向的电场分量被透射；垂直于它的分量被吸收。

    马吕斯定律

    对于非偏振光：

    非偏振光的电场振荡可以分解成两个强度相等的分量。

    因此，从偏振片出射的偏振光强度是入射光强度的一半： \(\(I = I_0/2\)\)

    对于偏振光：

    只有平行于偏振方向的分量 \(E_y = E\cos\theta\) 能透射。

    因此出射波强度为： \(\(I = I_0\cos^2\theta\)\)

    两个偏振片

    最初非偏振的光通过两个偏振片 P1（起偏器）和 P2（检偏器）。

    • 如果偏振方向平行，P1 透射的所有光都被 P2 透射
    • 如果垂直，没有光通过第二个偏振片

    反射偏振¶

    基本原理

    偏振光最常见的来源之一是从电介质介质反射。

    考虑入射到玻璃表面的非偏振光。入射光的电场 \(\vec{E}\) 可以分解成两个等大分量：一个垂直于入射面，另一个平行于入射面。

    一般情况

    一般地，反射光是部分偏振的。

    布儒斯特角¶

    布儒斯特角

    当光以特定的入射角（称为布儒斯特角 \(\theta_B\)）入射时，反射光是完全偏振的。

    实验发现，在入射角 \(\theta_B\) 时，反射光和折射光相互垂直：

    \[\theta_B + \theta_r = \frac{\pi}{2}\]
    推导

    根据斯涅尔定律 \(n_i \sin\theta_B = n_r \sin\theta_r\)：

    \[n_i \sin\theta_B = n_r \sin\theta_r = n_r \sin\left(\frac{\pi}{2} - \theta_B\right) = n_r \cos\theta_B\]
    \[\theta_B = \tan^{-1}\frac{n_r}{n_i}\]

    如果入射光和反射光在空气中传播，可以近似 \(n_i\) 为 1，所以 \(n_r = \tan\theta_B\)

    应用

    布儒斯特角在激光腔设计、太阳镜减少眩光等领域有重要应用。

    干涉（Interference）¶

    Overview

    本讲涵盖波的叠加、干涉条件、杨氏双缝实验以及薄膜干涉。

    波的叠加¶

    波动方程¶

    标量波动方程

    电磁波的每个场分量（\(E_x, E_y, E_z, B_x, B_y, B_z\)）都满足三维标量微分波动方程：

    \[\frac{1}{v^2}\frac{\partial^2\phi}{\partial t^2} = \frac{\partial^2\phi}{\partial x^2} + \frac{\partial^2\phi}{\partial y^2} + \frac{\partial^2\phi}{\partial z^2}\]

    线性叠加原理

    这个方程是线性的：\(\vec{\phi}(\vec{r},t)\) 及其导数只以一次幂出现。

    因此，如果 \(\vec{\phi}_i(\vec{r},t)\) 是解，它们的任意线性组合也是解： \(\(\vec{\phi}(\vec{r},t) = \sum_{i=1}^n C_i \vec{\phi}_i(\vec{r},t)\)\)

    例子¶

    三角公式¶

    和差化积公式

    \[\cos(\alpha + \beta) = \cos\alpha\cos\beta - \sin\alpha\sin\beta\]
    \[\cos(\alpha - \beta) = \cos\alpha\cos\beta + \sin\alpha\sin\beta\]
    \[\cos\alpha + \cos\beta = 2\cos\frac{\alpha + \beta}{2}\cos\frac{\alpha - \beta}{2}\]
    \[\cos\alpha - \cos\beta = -2\sin\frac{\alpha + \beta}{2}\sin\frac{\alpha - \beta}{2}\]

    代数叠加法¶

    设两波为：

    \[E_1 = E_{01}\cos(\alpha_1 - \omega t)\]
    \[E_2 = E_{02}\cos(\alpha_2 - \omega t)\]

    其中 \(\alpha_i = kx_i + \phi_i\)，\(x_i\) 是从光源 \(s_i\) 到观察点的距离。

    叠加结果

    两波的线性组合为： \(\(E \equiv E_0\cos(\alpha - \omega t) = E_1 + E_2\)\)

    得到： \(\(E_0\cos\alpha = E_{01}\cos\alpha_1 + E_{02}\cos\alpha_2\)\) \(\(E_0\sin\alpha = E_{01}\sin\alpha_1 + E_{02}\sin\alpha_2\)\)

    即：\(\vec{E}_0 = \vec{E}_{01} + \vec{E}_{02}\)

    干涉项

    \[E_0^2 = E_{01}^2 + E_{02}^2 + 2E_{01}E_{02}\cos(\alpha_2 - \alpha_1)\]

    合成强度不是分量强度的简单相加！

    额外的贡献 \(2E_{01}E_{02}\cos(\alpha_2 - \alpha_1)\) 称为干涉项。

    相位差来源

    \[\delta = \alpha_2 - \alpha_1 = \frac{2\pi}{\lambda}(x_2 - x_1) + (\phi_2 - \phi_1)\]

    相位差可能来自： - 两波传播的光程差 - 初相位差

    复数方法¶

    复数表示的优势

    处理简谐波叠加时，使用复数表示在数学上通常更方便。

    波函数 \(E_1 = E_{01}\cos(\alpha_1 - \omega t) = E_{01}\cos(kx_1 - \omega t + \phi_1)\) 可以写成：

    \[\tilde{E}_1 = E_{01}e^{i(\alpha_1 - \omega t)} = E_{01}e^{i\alpha_1}e^{-i\omega t}\]

    （如果我们只关心实部）

    勘误

    \(E_0^2 = (E_0 e^{i\alpha})(E_0 e^{-i\alpha})\)

    相量叠加法¶

    相量

    我们可以将具有振幅和相位的波映射到二维平面中的向量，称为相量。

    方法总结¶

    三种方法的统一

    三种方法都涉及二维空间中的叠加：

    方法 空间类型
    相量叠加 二维实空间中的向量加法（\(x\) 和 \(y\) 分量）
    复数方法 复平面中复数的加法（实部和虚部）
    代数/三角方法 二维希尔伯特空间中函数的加法（\(\cos\omega t\) 和 \(\sin\omega t\) 的线性组合）

    自然光¶

    为什么普通光源不干涉

    你可能认为两根细白炽灯丝发出的光会干涉。

    但实际上不会，因为光是由导线中大量原子随机、独立地在极短时间内（纳秒量级）发射的。

    这种光被称为不相干的。

    结果

    在观察屏上任意给定点，两光源的波之间的干涉在完全相长和完全相消之间快速随机变化。

    屏幕看起来是均匀照明的（在我们的观察时间尺度上）。

    干涉条件¶

    干涉观察条件

    要观察上述两波的干涉，需要以下条件：

    1. 两束光必须有（几乎）相同的频率 \(\omega\) - 否则相位差随时间变化，干涉图样会被平均掉

    2. 干涉波有（几乎）相等的振幅时，图样最清晰（对比度最大）

    3. 光源之间可以有初相位差，但必须保持恒定 - 两光源被称为相干的

    历史背景

    在激光出现之前，没有两个独立光源能够保持足够长时间的恒定相对相位来产生可观察的干涉图样。

    惠更斯原理¶

    惠更斯原理

    波前上的每一点都可以看作是从该点向外扩展的球面次级子波的源。

    当波撞击带有小开口的障碍物时，可以看到波从开口向外扩展。注意在这种情况下，波长大于开口。

    杨氏双缝实验¶

    实验装置

    • 屏幕 A 上的狭缝 \(S_0\) 产生能够同样照明屏幕 B 上狭缝 \(S_1\) 和 \(S_2\) 的空间相干光束
    • 注意：空间不相干来自于现实光源（如灯泡）包含的广泛分布的点源快速随机变化相位（由于发射过程的颗粒性质）
    • 现在，屏幕 A 不再需要，激光的平面波可以提供实验所需的空间相干性

    问题

    光波在杨氏双缝干涉实验中产生条纹，但究竟是什么决定了条纹的位置？

    换句话说，离开狭缝的光是同相的。

    然而，这些波在点 P 处的电场分量不同相，随时间变化为：

    \[E_1 = E_0\cos(kr_1 - \omega t) = E_0\cos(kL + \beta - \omega t)\]
    \[E_2 = E_0\cos(kr_2 - \omega t) = E_0\cos(kL - \beta - \omega t)\]

    其中 \(L = (r_1 + r_2)/2 = \sqrt{D^2 + y^2}\)，相位差 \(\delta_2 = 2\beta = k\Delta L = \frac{2\pi d}{\lambda}\sin\theta\)

    强度公式

    总强度为： \(\(I \propto 2E_0^2[1 + \cos(2\beta)]\)\)

    或 \(\(I = I_{max}\cos^2\beta\)\)

    干涉条件

    亮条纹出现当：\(\Delta L = d\sin\theta = m\lambda\)（\(m\) 为整数）

    暗条纹出现当：\(\Delta L = d\sin\theta = (m + \frac{1}{2})\lambda\)（\(m\) 为整数）

    我们可以找到任意条纹的角度 \(\theta\)，并用 \(m\) 值标记条纹。

    条纹间距

    对于 \(\Delta\theta\)： \(\(d(\sin\theta_1 - \sin\theta_2) = \frac{\lambda}{2}\)\)

    \[d\cos\left(\frac{\theta_1 + \theta_2}{2}\right)\Delta\theta = \frac{\lambda}{2}\]
    \[\Delta\theta = \frac{\lambda}{2d\cos\theta}\]

    薄膜干涉¶

    反射相移

    从高折射率介质表面反射时，光线 \(r_1\) 有额外的半波长反射相移。

    光线 \(r_2\) 没有这种相移。

    光程差

    光线 \(r_1\) 和 \(r_2\) 还有光程差 \(2L\)，发生在折射率为 \(n_2\) 的介质中。

    介质中的波长为：\(\lambda_2 = \frac{v_2}{f} = \frac{c}{n_2}\frac{1}{f} = \frac{\lambda}{n_2}\)

    干涉条件

    相长干涉（亮）当： \(\(2L = \left(m + \frac{1}{2}\right)\frac{\lambda}{n_2}\)\)（\(m\) 为整数）

    相消干涉（暗）当： \(\(2L = m\frac{\lambda}{n_2}\)\)

    极薄薄膜¶

    顶部的黑色区域

    薄膜非常薄时，顶部出现黑色区域。

    牛顿环¶

    牛顿环

    牛顿环是由入射到凸透镜与平板之间（或两个合适透镜之间）的薄空气膜上的光形成的干涉图样。

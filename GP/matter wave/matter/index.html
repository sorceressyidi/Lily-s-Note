    物质波（Matter Waves）¶

    概述

    本讲介绍物质波的概念，包括双缝干涉实验、德布罗意假说、电子衍射和海森堡不确定性原理。

    干涉实验的两个版本¶

    标准版双缝实验¶

    托马斯·杨实验（Thomas Young, 1801）

    在标准版双缝实验中，光照射在屏幕 B 上，B 上有两条狭窄的平行狭缝。

    从两个狭缝出射的光波通过衍射展开并在屏幕 C 上叠加，通过干涉形成交替的强度极大和极小的图案。

    光子探测实验

    在屏幕 C 的平面上某点放置一个微小的光子探测器 D（光电器件，吸收光子时会发出咔嗒声）：

    • 探测器产生一系列随机间隔的咔嗒声
    • 每次咔嗒声表示通过光子吸收从光波向屏幕传递能量
    • 如果缓慢移动探测器，咔嗒率会增加和减少，完全对应干涉条纹的极大和极小

    关键结论

    • 我们无法预测光子何时会被探测到屏幕 C 上的某一点
    • 光子在各个点以随机时间被探测
    • 我们可以预测：在指定时间间隔内单个光子被探测到特定点的相对概率与该点的光强成正比

    概率与振幅

    光波在任意点的强度 \(I\) 与 \(E_m\) 的平方成正比。

    因此，光子在光波中某给定点附近小体积内被探测的概率（每单位时间间隔）与该点波的电场矢量振幅的平方成正比。

    单光子版实验¶

    惊人发现

    光源极其微弱，一次只发射一个光子，间隔随机。

    令人惊讶的是，如果实验运行足够长时间，干涉条纹仍然会逐渐建立！

    令人困惑的问题

    • 如果光子一次一个通过装置，给定光子通过屏幕 B 的哪个狭缝？
    • 光子如何"知道"还有另一个狭缝存在，从而产生干涉？
    • 单个光子能否以某种方式同时通过两个狭缝并与自己干涉？

    推测

    因为最终在屏幕上建立了干涉图案，我们只能推测每个光子从源到屏幕以波的形式传播，这个波填满源与屏幕之间的空间。

    我们可以预测能量转移发生在屏幕上任意给定点的概率：

    • 转移倾向于发生在干涉图案的亮条纹区域
    • 转移倾向于不发生在暗条纹区域

    因此，从源传播的波是一个概率波（probability wave），在屏幕上产生"概率条纹"图案。

    光作为概率波¶

    双缝实验的启示

    • 光在源中以光子形式产生
    • 在探测器中以光子形式吸收
    • 在源与探测器之间以概率波形式传播

    概率密度与概率振幅

    在空间某点 \(P\) 探测到光子的概率密度取决于该点的辐照度 \(I \propto E_0^2\)。

    因此，点 \(P\) 的净 \(E_0\) 可以解释为概率振幅（probability amplitude）。

    概率振幅是一个量，其平方给出概率密度。

    深入学习

    要进一步了解，需要学习量子电动力学（QED）——光与物质相互作用的量子理论。

    扩展到所有粒子¶

    德布罗意假说（De Broglie Hypothesis）¶

    从光到物质

    光束是波，但它只在点处通过光子向物质传递能量和动量。

    电子是具有能量和动量的粒子。为什么我们不能把运动电子束——或任何其他粒子——看作物质波呢？

    德布罗意波长

    1924 年，路易·德布罗意提出可以为动量大小为 \(p\) 的粒子赋予波长 \(\lambda\)：

    \[\lambda = \frac{h}{p}\]

    这被称为运动粒子的德布罗意波长。

    电子衍射¶

    应用

    电子衍射和中子衍射用于研究固体和液体的原子结构，电子衍射常用于研究原子结构。

    电子干涉¶

    单电子干涉实验

    在最近的实验中，当电子一个接一个地通过双缝装置时，建立了干涉图案。当电子击中观察屏时，会产生闪光，其位置被记录下来。

    更多实验

    类似的干涉已在质子、中子和各种原子中得到证明：

    年份 粒子
    1994 碘分子 \(\text{I}_2\)
    1999 富勒烯（巴基球）\(\text{C}_{60}\) 和 \(\text{C}_{70}\)

    粒子之间会相互干涉吗？

    也许它们会碰撞……

    实验验证：在低强度下重复实验，使得任意给定时刻干涉区域只有一个粒子。

    物质波¶

    牛顿物理 vs 物质波¶

    牛顿物理的预期

    在牛顿物理中，粒子只知道它通过的那个狭缝，不知道其他狭缝是开是关还是存在。

    因此，当两个狭缝都打开时：\(P_{12} = P_1 + P_2\)

    结果

    显然，没有条纹（牛顿物理预测）

    考虑物质波

    电子以团块形式到达，像粒子一样，但这些团块到达的概率分布像波的强度分布。

    概率振幅¶

    引入概率振幅

    • 添加振幅 \(A\)
    • 引入概率振幅 \(\psi\)，它是一个复数
    • 理想实验中事件的概率由 \(|\psi|^2 = \psi^* \times \psi\) 给出

    叠加原理

    当一个事件可以以几种不同方式发生时，该事件的概率振幅是每种方式单独考虑时概率振幅的和：

    \[\psi = \psi_1 + \psi_2 + \cdots\]

    事件的概率为：

    \[P = |\psi|^2 = |\psi_1|^2 + |\psi_2|^2 + 2\Re(\psi_1^*\psi_2) + \cdots\]

    注：\(\Re\) 表示取实部

    干涉项

    干涉项 \(2\Re(\psi_1^*\psi_2)\) 导致实验中观察到的 \(P\) 的快速振荡。

    "哪条路"实验（Which-Way Experiment）¶

    关键发现

    如果执行的实验能够确定实际走的是哪条路径，干涉就会消失。

    实验结果

    "哪条路"实验告诉我们，事件的概率是每条路径概率的和：

    \[P = |\psi|^2 = |\psi_1|^2 + |\psi_2|^2\]

    这与经典情况完全相同。

    电子的行为

    如果我们观察到电子通过特定狭缝，它的行为就像通过那个狭缝一样；

    当没有被观察时，它的行为就像没有特定路径（没有通过特定狭缝）一样。

    为什么观察会产生影响？

    要以与狭缝间距 \(d\) 相当的分辨率看到电子（以知道它走了哪条狭缝），需要波长 \(\lambda < d\) 的光，这是标准波动理论。

    但是，光是由光子组成的，每个光子动量 \(p > \dfrac{h}{d}\)。

    所以，测量电子位置扰动了它的动量。

    观察行为中传递给电子的动量是不确定的。

    这是海森堡不确定性原理的体现。

    海森堡不确定性原理¶

    核心要点

    海森堡不确定性原理不是测量引起的效应，而是物质内在波动性质的结果。

    原理内容

    量子物理的概率性质对探测粒子位置和动量施加了重要限制。

    即，不可能同时以无限精度测量粒子的位置 \(\vec{r}\) 和动量 \(\vec{p}\)。

    不确定性关系（海森堡，1927）

    \[\Delta x \cdot \Delta p_x \geq \hbar\]
    \[\Delta y \cdot \Delta p_y \geq \hbar\]
    \[\Delta z \cdot \Delta p_z \geq \hbar\]

    物理意义

    这些关系源于电子和其他粒子是物质波，重复测量它们的位置和动量涉及概率，而非确定性。

    在这些测量的统计中，\(\Delta x\) 和 \(\Delta p_x\) 可以看作测量值的展宽（实际上是标准差）。

    常见疑问

    问：我们能否非常精确地测量 \(p_x\)，然后再非常精确地测量电子出现的位置 \(x\)？这不意味着我们同时非常精确地测量了 \(p_x\) 和 \(x\) 吗？

    答：不对！虽然第一次测量可以给我们精确的 \(p_x\) 值，但第二次测量必然改变这个值。

    确定动量的情况¶

    具有确定动量的电子

    考虑一个具有确定 \(k\) 值的电子，根据德布罗意关系，意味着确定的动量 \(p_x = \hbar k\)。

    因此 \(\Delta p_x = 0\)。

    由海森堡不确定性原理，这意味着 \(\Delta x \to \infty\)。

    波函数是什么形式？

    朴素猜测可能是 \(\sin kx\) 或 \(\cos kx\)。

    但它们具有空间变化，与我们的直觉不一致。

    波函数

    为了用波表示电子，我们需要一个波函数，它具有波长 \(\lambda = 2\pi/k\)，但其平方在 \(x\) 方向不应有任何变化（确定动量）：

    \[\psi(x,t) = e^{i(kx-\omega t)}\]
    验证：波函数平方为常数

    计算波函数平方 \(|\psi|^2\)：

    \[|\psi|^2 = e^{i(kx-\omega t)} \cdot e^{-i(kx-\omega t)} = 1\]

    这意味着在给定时间 \(t\)，波函数的平方在 \(x\) 方向是常数，没有关于 \(x\) 的变化。

    波函数的意义

    现在，电子在哪里？为什么是复数？

    • 如果我们现在测量 \(p_x\)，得到 \(p_x = \hbar k\)，没有不确定性
    • 但粒子以相同概率存在于任何地方，所以 \(\Delta x = \infty\)
    • 海森堡不确定性原理没有被违反

    测量位置后¶

    位置测量的影响

    如果我们测量 \(x\)，会在某处 \(x_0\) 找到电子。

    一旦找到它，它就不可能在其他地方。所以波函数突然坍缩为：

    \[\psi(x) = \delta(x - x_0)\]

    动量还是 \(p_x = \hbar k\) 吗？

    \(\delta\) 函数的傅里叶变换告诉我们：

    \[\bar{\psi}(p) = \mathcal{F}(\psi(x)) = \text{常数}\]

    在这种情况下，\(\Delta x = 0\) 但 \(\Delta p = \infty\)。

    同样，海森堡不确定性原理没有被违反。
